Quem está inadimplente?

Veja o que venceu, quanto é e de qual turma, sem cruzar listas. Renegocie direto da cobrança.

Essa turma dá lucro?

O custo de professores e das despesas é dividido entre as turmas, e você vê o resultado de cada uma.

Quanto sobrou este mês?

Receita recebida menos salários e despesas, com comparação com o mês anterior.

Perguntas frequentes

Preciso trocar o sistema que já uso para a secretaria?

Não. O Class Cash cuida do financeiro e pode conviver com o seu sistema acadêmico.

Consigo trazer meus dados de planilha?

Sim. Há modelos de planilha para turmas, professores, alunos e matrículas.

Os dados da minha escola ficam separados dos de outras?

Sim. Cada escola enxerga apenas os próprios dados.
